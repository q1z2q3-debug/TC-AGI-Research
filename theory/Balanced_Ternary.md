# TC-AGI Balanced Ternary Foundation

## Core Principle

TC-AGI uses balanced ternary as the primitive cognitive unit.

State space:

```
-1 : opposition / inhibition
 0 : harmony / potential / transition
+1 : activation / creation
```

The neutral state is not empty. It represents a generative equilibrium where new structures can emerge.

## Cognitive Interpretation

Binary systems represent existence through two poles. Balanced ternary introduces a third state that enables transformation between opposites.

The fundamental cognitive operation is not classification but evolution:

```
state + relation + transition = cognition
```
